# 🌡️ Termômetro da Verdade

**Um jogo educativo e interativo de Verdadeiro ou Falso sobre temperatura, clima e mudanças climáticas.**

[**🎮 Jogar agora**](https://ernandes-sobreira.github.io/termometro-da-verdade/) · [Ver código-fonte](https://github.com/ernandes-sobreira/termometro-da-verdade)

## O jogo

O **Termômetro da Verdade** convida o jogador a avaliar afirmações sobre climatologia, efeito estufa, aquecimento global e ciência do clima. Depois de cada resposta, o jogo apresenta uma explicação científica para apoiar a aprendizagem.

O termômetro animado representa **o progresso de acertos no desafio**, não uma temperatura real: começa em 0% e sobe em parcelas proporcionais ao número total de questões a cada acerto. Só chega a 100% se todas as questões forem respondidas corretamente.

## Como jogar

1. Acesse o link do jogo.
2. Selecione o nível **Básico**, **Intermediário**, **Difícil** ou **Carbonauta**.
3. Leia cada afirmação e escolha **Verdadeiro** ou **Falso**.
4. Confira o feedback e a explicação antes de avançar.
5. Ao concluir, veja seu resultado e, se desejar, registre seu nome no ranking.

O ranking organiza os resultados por quantidade de acertos; em caso de empate, o menor tempo vence. Os níveis são independentes.

## Principais recursos

- Quatro níveis de dificuldade, com ordem das afirmações embaralhada.
- Feedback imediato e explicações educativas.
- Termômetro animado que sobe com os acertos acumulados.
- Cronômetro, contadores de acertos/erros, sequência e barra de progresso.
- Ranking online por dificuldade usando Firebase Cloud Firestore.
- Interface responsiva para celular, tablet e computador.
- Respeito à preferência do dispositivo por movimento reduzido.

## Como executar

O jogo utiliza HTML, CSS e JavaScript no arquivo `index.html`. Abra-o em um navegador moderno. As perguntas funcionam localmente, mas o ranking necessita de internet e de configuração válida do Firebase. Para publicação, este repositório inclui um fluxo de GitHub Pages.

## Uso educacional

Material para atividades de Ciências, Biologia, Geografia, Ecologia e educação ambiental. É recomendado discutir as explicações após as respostas, distinguindo afirmações falsas, evidências e conceitos científicos.
